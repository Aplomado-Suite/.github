# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| Development | :x:            |

---

## Reporting a Vulnerability

We take the security of the Aplomado Suite ecosystem seriously. If you discover a vulnerability, please report it privately instead of opening a public issue.

### How to Report

1. **Email Us Directly:** Send details of the issue to **grolarlabs+aplomado@protonmail.com**.
2. **Provide Details:** Include steps to reproduce the flaw, a minimal proof-of-concept if possible, and impact details.

### Response Timeline

* **Acknowledgement:** Within 48 hours.
* **Status Updates:** Every 3 business days until resolved.
* **Fix Target:** Critical issues will be patched as a priority release.
