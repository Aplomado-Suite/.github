# Contributing Guidelines

Thank you for considering contributing to a part of the Aplomado Suite! We welcome bug fixes, documentation updates, and new feature additions.

---

## Quickstart Workflow

1. **Fork the Repository**  
   Click **Fork** at the top right of the GitHub repository page.

2. **Clone Your Fork**
   ```bash
   git clone https://github.com/Aplomado-Suite/repo-name.git
   cd repo-name
   ```

3. **Create a Feature Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make Changes & Commit**  
   Keep commits focused and write clear commit messages in the imperative mood:
   ```bash
   git commit -m "Add responsive layout to header component"
   ```

5. **Push & Open Pull Request**
   ```bash
   git push origin feature/your-feature-name
   ```
   Open a PR against the `main` branch on GitHub with a summary of changes.

---

## Guidelines & Best Practices

* **Scope:** Keep pull requests concise and limited to one bug fix or feature.
* **Coding Style:** Ensure your code matches existing style conventions and passes all testing.
* **Issue Reporting:** Check existing issues before opening a new one. Include steps to reproduce any reported bugs.
